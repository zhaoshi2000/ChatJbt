# 逗包 v1.2.0 — 多网页与多账号隔离版

基于本项目 v1.1.0 完整源码升级。保留 Java 21 单机后端、默认 48643 端口、本地网页、Manifest V3 无侧边栏扩展。**不是把旧 UI 加上账号下拉框；任务调度、数据访问、网页状态、工作标签页都加上账号和会话边界。**

首次操作见 **START_HERE.md**，包括 A/B 账号独立窗口和配对步骤。默认 `provider=browser`，不使用模拟回答，不要求 API Key。

## 1. 可以怎样使用

```
Java 后端 127.0.0.1:48643（只需一份）
├── 账号 A：专属令牌 A + 独立浏览器数据目录 A
│   ├── 逗包网页 1 → 会话 A1 → ChatGPT 工作标签页 A1
│   ├── 逗包网页 2 → 会话 A2 → ChatGPT 工作标签页 A2
│   └── 逗包网页 3 → 再次查看 A1，不会重新发送问题
└── 账号 B：专属令牌 B + 独立浏览器数据目录 B
    ├── 逗包网页 4 → 会话 B1 → ChatGPT 工作标签页 B1
    └── 逗包网页 5 → 会话 B2 → ChatGPT 工作标签页 B2
```

同一账号只维护一个 ChatGPT 工作标签页，多会话按队列顺序切换；不同账号各自使用独立浏览器配置文件和队列。一次点击发送会先创建任务，再由扩展自动唤醒工作页，不需要加载完成后再点一次。打开网页不是自动创建模型对话；第一次提交本地会话后才建立对应关系。

聊天输入框支持粘贴或选择图片，也能回传并下载 ChatGPT 生成的图片。模型菜单支持“保持当前、5.6 即时、5.6 思考、5.6 Pro、6 Pro”；每条任务在发送前通过 ChatGPT 可见页面菜单切换并核验模型。实际可用模型仍取决于当前登录账号的权限，模型不可用时任务不会用其他模型冒充发送。

每页选中的会话存放在 URL 的 `?c=`，草稿和待确认发送编号使用按账号/会话区分的 `sessionStorage`。只有账号连接配置在该浏览器配置文件内部共享。使用按钮新开页面带 `noopener`。浏览器自身“复制标签页”可能复制会话存储的初始状态；复制之后仍是独立存储，同一请求编号由后端幂等保护。

## 2. 登录隔离与真实边界

本地工作区不等于真实 ChatGPT 账号。名称“账号 A”只是用户标签。程序不读取或上传 Cookie、登录 session、密码，不尝试从网页头像或标题推断账号身份；需要你在独立配置文件里正确登录。

`open-account-A.bat` / `open-account-B.bat` 调用 `scripts/Open-AccountWindow.ps1`，以不同 `--user-data-dir` 打开 Edge/Chrome。每个配置文件首次都要手动加载扩展并配对专属令牌。**普通标签页、普通新窗口不等同于独立配置文件**；本版禁用扩展的无痕模式，避免误当成隔离方案。

独立数据目录：

```
%LOCALAPPDATA%\Doubao\BrowserProfiles\edge-a
%LOCALAPPDATA%\Doubao\BrowserProfiles\edge-b
```

Chrome 对应 `chrome-a` / `chrome-b`。同编号在不同浏览器里也是不同配置文件。脚本不删除/复制现有浏览器数据，不开启调试端口，不自动修改浏览器企业策略，不强制关闭浏览器；企业策略禁止独立配置文件或扩展安装时，需要管理员处理。可显式选择：

```powershell
.\open-account-window.bat -Profile work -Browser Edge
.\open-account-window.bat -Profile personal -Browser Chrome
```

一个扩展实例有随机持久 clientId。服务器拒绝将同一个 clientId 绑定到两个本地账号，也拒绝让一个账号同时绑定两个不同 clientId。插件重装或切换配置文件后，需要管理员在无运行任务时重置该账号令牌与绑定。**不要仅换令牌、在绑定期间退出/切换 ChatGPT 账号，或将两份浏览器数据目录复制合并。** 扩展不能防止用户手动切错真实上游身份。

本版是本机个人多账号工作台，**不是公网多租户认证产品**。后端仅监听 127.0.0.1，校验 Host、Origin、Bearer 令牌。不要改为 0.0.0.0 或直接暴露公网。主令牌和持有本机文件读取权限的人可以访问全部数据；聊天文件明文保存，账号边界不是对操作系统管理员的安全边界。

## OpenClaw / OpenAI 兼容调用

账号专属 Token 可作为 API Key 调用 `http://127.0.0.1:48643/v1`。支持 `/v1/models` 与 `/v1/chat/completions`（流式和非流式）。在 GBT 的“连接设置”中点“复制 OpenClaw 配置”，然后合并到 OpenClaw 配置即可。自定义 provider 使用 `api: "openai-completions"`，模型为 `gbt/gbt`。

调用期间必须保持对应账号的 Edge/Chrome 工作窗口、GBT 扩展和本机后端在线。接口默认仅允许本机回环访问，不应直接暴露到公网。

## 3. 配对变更

`data/local-token.txt` 沿用旧主令牌，但角色改为管理员，不能直接发消息或充当桥接账号。全新安装且尚无账号时，可直接在聊天页“连接账号”中一键生成第一个账号专属令牌，页面会回填并提供复制按钮，不必查找令牌文件。已有账号后的新增、查看和重置仍由“账号管理”使用管理员令牌完成。服务器只保存账号专属令牌的 SHA-256 摘要；创建和重置时返回原令牌一次。网页只在内存/输入框持有管理员令牌，关闭管理窗口清空；不存到浏览器 localStorage。

每个账号的专属令牌存于该配置文件的网页连接设置和扩展本地存储中。拥有账号令牌的人能访问该账号的数据，应当视为密码保管，不是可公开展示的编号。不要把任何令牌放进 URL、发给别人，或把 data、浏览器配置文件打包分享。

## 4. 消息调度与防串聊

- 所有新任务包含不可变的 `accountId / conversationId / requestId`。账号身份由服务端鉴权得到，不信任调用方指定其他账号。
- 任务列表、单任务、会话、正文、SSE、取消、删除、诊断均按账号鉴权。不属于当前账号的 ID 返回不可见，不能单纯改前端参数访问。
- 新本地会话新建空白工作标签页，不抢占当前普通聊天，不把所有任务塞进同一个“当前标签页”。首次记录上游 `/c/...` 后，绑定不可静默切换；同一账号的两个本地会话不能绑定同一个上游会话。
- 发送时自动创建或唤醒对应工作标签页并等待输入框；登录失效或长时间无法就绪时才聚焦工作页要求人工处理。
- worker 每个会话独立保存 lane、文档键和事件 outbox，但同一账号通过一个共享工作标签页串行执行；不同账号之间仍互不阻塞。
- 后端检查账号、已绑定 clientId、任务会话、lease 与顺序号。扩展检查 tabId、顶层 frame、documentKey、任务与账号。重载 worker 可以从本地 outbox 重传已保存事件，由服务器幂等确认。
- 浏览器重启/扩展重载后不复用旧的数字 tabId；只按已记录的原 `/c/` 地址恢复。没有安全地址、无法确认是否已提交时，显示需要核对，不会自动重发。
- 关闭逗包显示页面只停止观看；任务归后端和工作页负责。重新打开相同会话可恢复快照。关闭真正执行生成的 ChatGPT 页、浏览器退出或休眠不能保证继续生成。
- 同一 requestId 在同一账号同一会话中只对应同一消息，网络确认丢失显示“重试确认”，不会生成新请求编号。明确拒绝则保留草稿。
- 回复采用完整文本快照，不将页面重绘当成新增量重复追加。完成判断仍要求明确的回复操作区域与稳定文本，搜索/思考状态不会因为短暂停顿直接完成。

## 5. 数据与升级

```
data/
├── local-token.txt      管理员令牌（私密）
├── workspaces.json      账号、令牌摘要、绑定、会话元数据
├── backend.lock         防止同一个 data 被两个后端同时打开
└── tasks/*.json         按账号和会话标注的任务记录/状态/正文
```

从 v1.1.0 升级前停止任务和后端并备份 data。将整个 data 复制到新版本，启动时将没有 accountId 的旧任务转换到 `legacy-archive`。旧运行任务标为中断，不猜测旧上游账号，也不继续执行到新账号。管理员在网页“导出旧版记录”读取旧归档。旧版只有独立 task 历史，本版不会凭空猜测它们原本属于哪条会话。

数据格式已升级，回退旧程序时必须使用升级前备份。不要只备份 workspaces 或只备份 tasks：这两部分共同组成账号和会话状态。正常关闭后备份整个 data，浏览器数据目录另行备份。新版不会自动迁移 0.4.0 旧 `history.jsonl` 的自定义内容。

删除本地会话不删除 ChatGPT 网页中的会话。令牌重置不删除聊天记录。默认每账号最多保留约 2000 条任务，超过上限会清理最旧的已结束任务，运行任务不清理；需要长期保留请导出备份。旧归档不参与新账号的自动清理。

## 6. 文件与运行

| 文件 | 用途 |
|---|---|
| run-doubao-web.bat | 检查/启动 Java 后端，打开普通逗包网页 |
| open-account-A.bat / open-account-B.bat | 启动后端并打开独立账号浏览器窗口 |
| open-account-window.bat | 输入/指定更多窗口编号 |
| copy-token.bat | 将本地管理员令牌复制到剪贴板 |
| stop-backend.bat | 用主令牌正常停止这一份后端 |
| stop-all.bat | 先正常关闭，再安全识别/处理旧新项目服务；不关全部 Java 或浏览器 |
| diagnose.bat | 输出本机管理员诊断，不含令牌正文或聊天内容 |
| build.bat / scripts/build.sh | Windows / Linux 源码编译，需要 JDK 21+ |

参数 `config/application.properties`：端口 48643，provider=browser，队列每账号 20，bridge.concurrent=3（可改 1–5），task.timeout.seconds=900。端口变更时扩展也要设置为相同端口。启动脚本检查已有后端版本，不会占着旧后端启动新网页。

## 7. 保留的可选模式

`PROVIDER=mock` 只用于离线演示，UI 明示不是模型；默认不启用。

`PROVIDER=openai` 保留官方 Responses API 接入；需设置 `OPENAI_API_KEY`、项目可用的 `OPENAI_MODEL`。本版只把同一账号、同一会话最近 20 轮已完成消息与当前问题组合为上下文，不拼接其他会话内容。**所有本地账号仍共用环境变量里的 API Key**；本版未实现每账号独立 API 密钥配置。此分支没有完成真实 API 调用/计费验证；多 ChatGPT 登录账号的目标使用 browser 模式。
